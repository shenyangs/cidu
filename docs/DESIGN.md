# 词渡 0.5 设计约束

macOS 原生 SwiftUI，面向非技术用户。主任务只有来源、去向、开始；迁移记录和文件工具为次级入口。Apple Liquid Glass 是用户指定方向，macOS 26+ 使用 glassEffect；旧系统 regularMaterial，减少透明度时不透明背景。

真实进度来自读取、逐条合并、原生引擎验证、安装回读。词条流只显示实际处理过的条目，不使用伪造计数或计时推进；支持隐藏内容和减少动态效果。版本、账号、格式不明时在原位提示原因，不声称迁移完成。

当前无法验证所有路线时禁用主动作，明确展示适配状态。后续优先补齐每个输入法的自动读取与事务安装，避免让用户处理文件包。


## 0.5.1 迁移前检查
选择两端后自动只读检查安装与版本、来源权限/设置入口或导出文件、目标唯一账号与结构、写权限及备份目录。问题优先显示并提供处理按钮；切换两端、文件或返回应用后重查，旧异步结果不覆盖新选择。检查期间和任一失败时禁用迁移，执行前再次检查。完整导出及原生引擎验证仍在迁移阶段进行，不能将基础检查通过称为完整迁移成功。
